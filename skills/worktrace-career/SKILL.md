# Worktrace 本机工作台

点击聊天上方 Worktrace 打开原版画布。此版本不向 Harness 模型暴露任何资料读取或修改工具。
不要读取 Worktrace JSON、恢复快照或导出文件，不要把本机材料放入聊天或云模型。不要用 shell 绕过面板。
请在工作台导入材料、核对经历、匹配岗位、预览并导出简历。AI 使用本地 Ollama qwen3:4b，禁用云功能且进程仅可连接本机。没有本地模型时停止，不回退云端。
资料修改须由用户在原生面板确认。工作台不自动投递或联系招聘方。
